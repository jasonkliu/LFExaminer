# LF Examiner Theater List

It is a backup from <https://lfexaminer.com/theaters/>.

The extracted dataset is available as [Theaters.csv](Theaters.csv).

This list includes IMAX theaters, whether film or digital, and theaters that originally had one of the 70mm film formats listed below, as well as digital fulldome theaters larger than 60 feet in diameter.

Updated Oct. 17, 2021.

## Format key

| Code | Meaning |
| --- | --- |
| 1070 | 10-perf, 70mm film |
| 1570 | 15-perf, 70mm film |
| 870 | 8-perf, 70mm film |
| D | Digital (xenon) |
| DL | Digital, single laser projector (IMAX+DL=”Commercial” or Laser Dome) |
| DLx | Digital, multiple laser projectors (IMAX+DL2=”GT” Laser) |

## Theater Type key

| Code | Meaning |
| --- | --- |
| C | Commercial, non-multiplex |
| CM | Commercial, multiplex |
| N | Institutional |
